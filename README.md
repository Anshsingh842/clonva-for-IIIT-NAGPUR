# Clonva - Your Study Buddy 📚

Clonva ek simple study-planner web app hai jo students ko roz padhai plan karne, track karne aur focus mein rehne mein help karta hai.

LIVE LINK-

https://clonva-for-iiit-nagpur-4.onrender.com

## ✨ Features

- 🏠 **Home** - Motivation message, stats cards (tasks, streak, progress) aur "Ask Your Question" box
- 📝 **Study Plan** - Task add karo, priority (High / Medium / Low) set karo, Done ya Delete karo
- 📅 **Calendar** - Monthly calendar jisme aapke tasks unki date par dikhte hain
- 📊 **Progress** - Progress bar jo dikhata hai kitna kaam complete hua
- ⏱️ **Focus Mode** - 25 minute ka Pomodoro timer (Start, Pause, Reset)
- 📚 **Notes** - Notes likho aur save karo
- 📷 **Camera** - Question ki photo select karne ka option (abhi demo hai)

## 🛠️ Tech Used

- HTML
- CSS
- JavaScript (vanilla, koi library nahi)
- `localStorage` - tasks aur notes browser mein hi save hote hain

## 🚀 Run Kaise Karein

1. Repo download ya clone karo
2. `index.html` file ko browser mein open karo

Kisi installation ki zaroorat nahi hai.

## ⚠️ Note

- Data sirf aapke apne browser mein save hota hai. Browser data clear karne par tasks aur notes delete ho jayenge.
- "Ask Your Question" abhi demo response deta hai. Real AI model baad ke version mein connect hoga.
